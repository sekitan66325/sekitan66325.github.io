# 真岡鐵道 車両運用資料ライブラリ＆目撃掲示板 完全仕様書・マニュアル

---

# 1. 一般ユーザー向け利用ガイド

## はじめに

本サイトは、有志の調査・目撃情報を基に真岡鐵道の車両運用データをまとめている非公式ライブラリ＆掲示板です。

どなたでも無料で運用資料の閲覧や目撃情報の投稿・検索が利用できます。

---

## 主な機能と使い方

### ① 運用資料の閲覧（「運用資料」タブ）

#### 現行ダイヤ・運用表の閲覧

モオカ14形、C12 66・50系（SLもおか）、DE10 1535などの運用PDFを閲覧できます。

各項目右側に表示される

```
[PDF / ○○KB]
```

は実際のファイルサイズを示しています。

#### 月別運用報告書

過去および当月分の運用報告書（PDF）を閲覧できます。

当月分は毎日早朝（3:40頃）に前日までの内容へ更新されます。

---

### ② 目撃情報の投稿（「目撃掲示板」タブ）

1. 画面上部の **「目撃情報を投稿する」** を選択します。
2. 以下の項目を入力します。

|項目|内容|
|---|---|
|投稿者名|必須・20文字以内|
|目撃情報（本文）|必須・1000文字・50行以内|
|暗証番号|必須・半角英数字4文字以上|

3. **「投稿する」** を押すと、投稿内容は即座に掲示板へ反映されます。

#### 記入例

```text
2026/07/21 22:06
145レ 14-2+14-6(A31+A6)
備考 / 西田井駅で目撃
```

---

### ③ 投稿の編集・削除

自分が投稿した記事の右下に表示される

- 編集
- 削除

ボタンを押します。

投稿時に設定した暗証番号を入力すると、

- 内容の編集
- 投稿の削除（非表示）

を行うことができます。

---

### ④ 目撃情報の検索

掲示板上部の

```
検索（日付・列車番号・車両）
```

欄へ、

- `145レ`
- `14-2`
- `2026/07/21`

などのキーワードを入力すると、該当する投稿だけがリアルタイムで表示されます。

---

## ご利用にあたっての注意事項

### 1. 現地・事業者様へのお問い合わせ厳禁

本サイトのデータは、有志による目撃・調査情報を基にした非公式データです。

真岡鐵道株式会社様へのお問い合わせは絶対におやめください。

---

### 2. 自分で目撃した情報のみ投稿してください

以下の内容は投稿しないでください。

- 他サイトからの転載
- SNSからの転載
- ライブカメラ映像
- 他人から聞いた情報

---

### 3. 誤投稿の修正マナー

誤った投稿を行った場合は、

暗証番号を利用してご自身で編集・削除してください。

「下は間違いです」などの連続投稿はご遠慮ください。

---

### 4. 連続投稿の制限

スパム防止のため、

投稿後約30秒間は次の投稿ができません。

時間を空けてから投稿してください。

## セキュリティ設計

### パスワード保護

- 投稿暗証番号
- 管理者パスワード

はすべて

**SHA-256**

でハッシュ化して保存します。

---

### セッション管理

管理者ログイン成功時、

UUIDトークンを生成し、

Google Apps Script の

```
CacheService
```

へ24時間保存します。

管理者APIはこのトークン認証が必須です。

---

### Soft Delete

削除時もデータは物理削除されません。

```
is_hidden = true
```

へ更新するだけです。

すべての操作は

```
edit_log
```

へ記録されます。

## 運行データ (timetable.json) 管理

### 1. データ編集の流れ
1. **リポジトリから読込**: 画面上部のステータスバーまたはタブ内から最新データを取得します。ブラウザ内に未プッシュの下書きがある場合は復元確認ダイアログが表示されます。
2. **列車を選択**: 左サイドバーの列車検索または一覧から編集したい列車を選択します。
3. **運行ルール・特定日・時刻表の編集**:
   - **運転曜日**: 「月」「火」「水」「木」「金」「土」「日」「祝」のピルボタンをクリックして運転する曜日を選択します（青色＝運転、非選択＝運休）。「全日」「平日のみ」「土休日のみ」「全休」のプリセットボタンも利用可能です。
   - **特定運転日 / 特定運休日**: 単一日付（`YYYY-MM-DD`）だけでなく、期間指定（`YYYY-MM-DD~YYYY-MM-DD`）にも対応しています。カレンダーピッカーから期間を選択するか直接入力して「追加」を押します。
   - **特定日・変更ダイヤ (schedule_variants)**: 特定日のみの時刻変更、延長運転（例：茂木行きを真岡止まりに変更、またはその逆）、SL重連運転などの特別ダイヤを設定できます。「基本時刻表からコピー」や「±N分の一括シフト」を活用することで迅速に設定可能です。
   - **日付指定の区間運休 (partial_cancellations)**: 特定の日付・期間に特定区間のみ運休する場合に設定します。
   - **基本時刻表データ (stations)**: 各駅の発着時刻を編集します。
4. **変更を適用 (メモリ上)**:
   - 編集完了後、「変更を適用 (メモリ上)」を押します。
   - 画面のリロードやタブ移動は行われず、編集中列車の状態を保ったままメモリおよびブラウザのローカルストレージに自動保存されます。
   - 変更された列車にはオレンジ色の「未反映マーク」が付きます。
5. **差分確認 (Diff)**:
   - ステータスバーの「差分確認」を押すと、GitHub最新データと比較した変更内容一覧（列車、項目、変更前・後）をモーダルで確認できます。
6. **GitHubへ反映 (プッシュ)**:
   - ステータスバーの「GitHubへ反映」ボタンを押すと、GASを経由してGitHubリポジトリの `train-state/data/timetable.json` に直接コミット・プッシュされます。
   - プッシュ完了後、GitHub Pagesのビルド（約1〜2分）を経て本番環境に自動反映されます。

---

## 運用ベース管理

曜日ごとにどの列車をどの運用（14-1〜14-7、A31、A601等）に充当するかを設定します。
- **安全な分離設計**: 運用ベース管理で充当列車を変更しても、各列車の運行ルール（SLや特定列車の運転日・運休日）が上書きされたり破壊されることはありません。
- 編集後、「変更を適用 (メモリ)」を押し、上部ステータスバーから「GitHubへ反映」を行います。

---

## 運行シミュレーション

「運行シミュレーション」タブでは、指定した日付（祝日・振替休日判定含む）において全列車がどのように運行されるかを事前にシミュレーション確認できます。
- 日付を選択すると、その日に運転される全列車、種別、方向、始発・終着駅、発着時刻、適用ダイヤ区分（通常／特別ダイヤ名）、充当運用が一覧表示されます。
- 新しい運行ルールや変更ダイヤを設定した際、本番反映前に意図通り動作するか即座に確認できます。

# 3. トラブルシューティング

|症状|原因・対処|
|---|---|
|投稿が読み込めない|GASのアクセス権限が「全員」になっているか確認してください。|
||script.js の GAS_URL が正しいか確認してください。|
|管理者ログインできない|admins シートの password_hash が正しいSHA-256ハッシュになっているか確認してください。|
||ブラウザの sessionStorage を削除して再試行してください。|
|PDFサイズが表示されない|HEADリクエストがCORS制限で拒否されている可能性があります。Webサーバー経由（http://またはhttps://）でアクセスしてください。|
