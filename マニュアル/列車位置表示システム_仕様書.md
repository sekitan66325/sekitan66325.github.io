### 1.2 サービス日（Service Date）と時間軸正規化
深夜24時以降および未明の臨時運用を「単一の運行日」として連続処理するため、**サービス日**および**サービス分数**への正規化を行う。

* **サービス日の定義**: 当日午前 `05:00:00` から翌日午前 `04:59:59` までを 1 つのサービス日として扱う。
* **有効時間軸範囲**: `300 <= service_minutes < 1740`（05:00〜28:59 / 29:00は排他境界）。
* **タイムゾーン**: クライアントおよびGoogle Apps Script (GAS) 双方で `Asia/Tokyo` を明示指定。

```javascript
/**
 * 暦日時(Date)をサービス日(YYYY-MM-DD)とサービス分数(300〜1739)に変換
 * @param {Date} calendarDateObj 
 * @returns {{ service_date: string, service_minutes: number }}
 */
function normalizeToServiceContext(calendarDateObj) {
  const formatter = new Intl.DateTimeFormat('en-US', {
    timeZone: 'Asia/Tokyo',
    year: 'numeric', month: '2-digit', day: '2-digit',
    hour: '2-digit', minute: '2-digit', hour12: false
  });
  const parts = Object.fromEntries(formatter.formatToParts(calendarDateObj).map(p => [p.type, p.value]));
  
  let year = parseInt(parts.year, 10);
  let month = parseInt(parts.month, 10) - 1;
  let day = parseInt(parts.day, 10);
  let hours = parseInt(parts.hour, 10);
  let minutes = parseInt(parts.minute, 10);

  // 環境依存による深夜0時の「24時」表記対策ガード
  if (hours === 24) hours = 0;

  if (hours < 5) {
    const prevDate = new Date(Date.UTC(year, month, day - 1));
    const serviceDateStr = prevDate.toISOString().slice(0, 10);
    const serviceMinutes = (hours + 24) * 60 + minutes; // 例: 01:30 -> 1530
    return { service_date: serviceDateStr, service_minutes: serviceMinutes };
  } else {
    const serviceDateStr = `${year}-${String(month + 1).padStart(2, '0')}-${String(day).padStart(2, '0')}`;
    const serviceMinutes = hours * 60 + minutes; // 例: 05:00 -> 300
    return { service_date: serviceDateStr, service_minutes: serviceMinutes };
  }
}
```

#### 運行ルール・特定日・期間指定の構文規則
* **`days_off`**: 運休する曜日の配列。日: 0、月: 1、火: 2、水: 3、木: 4、金: 5、土: 6。
* **`dates_run` / `dates_off`**:
  * 単一日付: `YYYY-MM-DD`（例: `2026-08-15`）
  * 期間指定: `YYYY-MM-DD~YYYY-MM-DD` または `YYYY-MM-DD..YYYY-MM-DD`（開始日と終了日を含む閉区間）
  * 祝日指定: `holiday`（内閣府祝日規定、ハッピーマンデー、春分・秋分、振替休日を自動判定）
  * 曜日指定: `sun`, `mon`, `tue`, `wed`, `thu`, `fri`, `sat`
  * 他列車・他運用連動: `train:103`（列車103が運転する日）、`op:A1`（運用A1が運転する日）
* **`schedule_variants`（特定日・変更ダイヤ）**:
  * `label`: 特別ダイヤ名（例：「SLもおか重連運転」）
  * `dates`: 適用する日付または期間の配列（例: `["2026-08-15", "2026-11-03~2026-11-05"]`）
  * `destination`: 行先上書き（省略時は基本行先）
  * `stations`: 特別ダイヤ施行時の各駅着発時刻配列
* **`partial_cancellations`（区間運休）**:
  * `date`: 適用する日付または期間（例: `2026-09-01~2026-09-05`）
  * `actual_start` / `actual_end`: 実質始発駅コード、実質終着駅コード

指定日 `service_date` に対して対象列車が運行されるか否かを以下の優先順位で評価する。

```
[判定ステップ]
1. dates_off（特定運休日）に service_date が含まれるか？ ➔ 含まれれば【運休 (false)】
2. dates_run（特定運転日）に service_date が含まれるか？ ➔ 含まれれば【運転 (true)】

4. service_date の曜日・祝日判定が days_off に該当するか？ ➔ 該当すれば【運休 (false)】
5. 上記すべての条件に該当しない場合 ➔ 【運転 (true)】
```

## 5. 列車状態計算エンジン (`TrainStateEngine.js`)

### 5.1 実効時刻計算および区間運休・遅延回復の適用

オーバーライドデータで指定された `actual_start` / `actual_end` の存在検証および駅順序（インデックス比較）検証を行い、不整合（タイポ、駅リスト不在、順序逆転）時は基本ダイヤに安全フォールバックする。

```javascript
function calculateActualTimetable(train, override) {
  const baseDelay = override?.delay_minutes || 0;
  const stationDelays = override?.station_delays || {};

  // 区間運休のバリデーションと適用
  let actualStart = train.stations[0].code;
  let actualEnd = train.stations[train.stations.length - 1].code;

  if (override?.actual_start && override?.actual_end) {
    const startIdx = train.stations.findIndex(s => s.code === override.actual_start);
    const endIdx = train.stations.findIndex(s => s.code === override.actual_end);

    // 両駅が存在し、かつ進行方向順序が正しい場合のみ適用
    if (startIdx !== -1 && endIdx !== -1 && startIdx <= endIdx) {
      actualStart = override.actual_start;
      actualEnd = override.actual_end;
    } else {
      console.warn(`[Data Anomaly] Invalid or reversed actual_start/end for ${train.train_id}. Falling back to full route.`);
    }
  }

  let isWithinActiveSegment = false;

  return train.stations.map((st) => {
    if (st.code === actualStart) isWithinActiveSegment = true;
    
    const isCancelled = !isWithinActiveSegment;
    const currentDelay = stationDelays[st.code] !== undefined ? stationDelays[st.code] : baseDelay;

    const arrMinutes = st.arr !== null ? timeStringToMinutes(st.arr) + currentDelay : null;
    const depMinutes = st.dep !== null ? timeStringToMinutes(st.dep) + currentDelay : null;

    const result = {
      code: st.code,
      arr_scheduled: st.arr,
      dep_scheduled: st.dep,
      arr_actual: arrMinutes,
      dep_actual: depMinutes,
      delay_minutes: currentDelay,
      is_cancelled: isCancelled
    };

    if (st.code === actualEnd) isWithinActiveSegment = false;

    return result;
  });
}

```

### 5.2 列車状態（4状態）の判定仕様

`ARRIVED_HOLD_MINUTES` により到着後5分間は画面に留め、その後 `OUT_OF_SERVICE` へ遷移させる。また、遅延回復時におけるゼロ除算・逆転を防ぐ分母ガード処理を組み込む。

| 状態フラグ (`state`) | 条件 | 画面上の意味 |
| --- | --- | --- |
| `OUT_OF_SERVICE` | `current_minutes < 始発駅dep` または `current_minutes >= 終着駅arr + 5分` | 運転時間外 / 圏外 |
| `STOPPED` | 途中駅において `arr_actual <= current_minutes < dep_actual` | 駅停車中（`arr === dep` の1分間は「通過/停車中」） |
| `RUNNING` | 駅間において `前駅dep_actual <= current_minutes < 次駅arr_actual` | 駅間走行中 |
| `ARRIVED` | 終着駅において `終着駅arr <= current_minutes < 終着駅arr + 5分` | 終着駅到着（5分間保持） |

```javascript
const ARRIVED_HOLD_MINUTES = 5; // 到着状態の画面保持時間（分）

function evaluateTrainState(actualStations, currentMinutes) {
  const activeStations = actualStations.filter(s => !s.is_cancelled);
  if (activeStations.length < 2) return { state: 'OUT_OF_SERVICE' };

  const firstStation = activeStations[0];
  const lastStation = activeStations[activeStations.length - 1];

  // 1. 始発発車前チェック
  if (currentMinutes < firstStation.dep_actual) {
    return { state: 'OUT_OF_SERVICE' };
  }

  // 2. 終着駅到着後の保持および時間外チェック
  if (currentMinutes >= lastStation.arr_actual) {
    if (currentMinutes < lastStation.arr_actual + ARRIVED_HOLD_MINUTES) {
      return { state: 'ARRIVED', station_code: lastStation.code };
    }
    return { state: 'OUT_OF_SERVICE' };
  }

  // 3. 各駅での停車チェック
  for (let i = 0; i < activeStations.length; i++) {
    const st = activeStations[i];
    if (st.arr_actual !== null && st.dep_actual !== null) {
      if (st.arr_actual === st.dep_actual && currentMinutes === st.arr_actual) {
        return { state: 'STOPPED', station_code: st.code, is_instant_stop: true };
      }
      if (st.arr_actual <= currentMinutes && currentMinutes < st.dep_actual) {
        return { state: 'STOPPED', station_code: st.code, is_instant_stop: false };
      }
    }
  }

  // 4. 駅間走行チェック（遅延回復用の分母ガード付）
  for (let i = 0; i < activeStations.length - 1; i++) {
    const fromSt = activeStations[i];
    const toSt = activeStations[i + 1];
    if (fromSt.dep_actual <= currentMinutes && currentMinutes < toSt.arr_actual) {
      // 遅延回復によるゼロ除算・数値不整合を防ぐガード（最小所要時間を1分に固定）
      const totalTime = Math.max(1, toSt.arr_actual - fromSt.dep_actual);
      const elapsedTime = currentMinutes - fromSt.dep_actual;
      const progress = Math.min(1.0, Math.max(0.0, elapsedTime / totalTime));

      return {
        state: 'RUNNING',
        from_station: fromSt.code,
        to_station: toSt.code,
        progress: progress
      };
    }
  }

  return { state: 'OUT_OF_SERVICE' };
}

```

### 6.2 GAS差分検知 & ログ処理プログラム

`PropertiesService` を利用し、前回の状態（テキスト・URL）と比較する。スクレイピング構造変化時やHTML未検出時は「パース失敗」として `status_code: "unknown"` へ安全フォールバックさせる。

```javascript
function checkAndLogOfficialInfo() {
  const URL = "[https://www.moka-railway.co.jp/](https://www.moka-railway.co.jp/)";
  const props = PropertiesService.getScriptProperties();
  
  const lastText = props.getProperty("LAST_NOTICE_TEXT") || "";
  const lastUrl = props.getProperty("LAST_NOTICE_URL") || "";

  try {
    const options = {
      muteHttpExceptions: true,
      headers: {
        "User-Agent": "MokaLineApp-NoticeMonitor/1.0 (+[https://sekitan66325.github.io/](https://sekitan66325.github.io/))"
      }
    };
    const response = UrlFetchApp.fetch(URL, options);
    if (response.getResponseCode() !== 200) {
      throw new Error("HTTP Status " + response.getResponseCode());
    }

    const html = response.getContentText("UTF-8");
    const parsedData = parseMokaInfoArea(html);

    const currentText = parsedData.text;
    const currentUrl = parsedData.url;

    // テキスト・URLともに変化がなければ処理終了
    if (currentText === lastText && currentUrl === lastUrl) {
      return;
    }

    // イベント種別の判定
    let eventType = "内容変更";
    if (lastText === "" || lastText.includes("平常")) {
      eventType = parsedData.isNormal ? "平常保持" : "新規発出";
    } else if (parsedData.isNormal) {
      eventType = "平常復旧";
    }

    // 差分が検知された時点でスクリプトプロパティを更新（次回判定の高速キャッシュ）
    props.setProperty("LAST_NOTICE_TEXT", currentText);
    props.setProperty("LAST_NOTICE_URL", currentUrl);

    // 平常から平常への初回記録移行（「平常保持」）はログ追記をスキップ
    if (eventType === "平常保持") return;

    // スプレッドシートへのログ追記
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName("Notice_Logs");
    if (!sheet) {
      sheet = ss.insertSheet("Notice_Logs");
      sheet.appendRow(["検知日時", "イベント種別", "お知らせ内容", "お知らせURL"]);
    }

  } catch (e) {

function parseMokaInfoArea(html) {
  const matchContainer = html.match(/<div[^>]*class="[^"]*info[^"]*"[^>]*>([\s\S]*?)<\/div>/i);
  
  // スクレイピング構造変更・未発見時のサイレントフォールバック防止
  if (!matchContainer) {
    console.error("[Scraper] info container not found - site structure may have changed");
    return { 
      text: "公式運行情報を取得できませんでした（真岡鐵道HPをご確認ください）", 
      url: "[https://www.moka-railway.co.jp/](https://www.moka-railway.co.jp/)", 
      isNormal: false, 
      parseFailed: true 
    };
  }

  const containerHtml = matchContainer[1];
  const matchLink = containerHtml.match(/<a[^>]*href="([^"]*)"[^>]*>([\s\S]*?)<\/a>/i);
  
  let text = "";
  let url = "";

  if (matchLink) {
    url = matchLink[1];
    text = matchLink[2].replace(/<[^>]+>/g, "").trim();
    if (url && !url.startsWith("http")) {
      url = "[https://www.moka-railway.co.jp](https://www.moka-railway.co.jp)" + (url.startsWith("/") ? "" : "/") + url;
    }
  } else {
    text = containerHtml.replace(/<[^>]+>/g, "").trim();
  }

  const isNormal = text.includes("平常");

  return { text, url, isNormal, parseFailed: false };
}
```

## 7. 画面描画・レイアウト仕様 (`Renderer.js`)

### 7.1 走行位置ビュー（公式運行情報バナー・推定位置・動的レーン分配）

* **公式運行情報バナー**:
* `status_code === "normal"`: 灰色背景に「公式: 平常通り運転しております」と表示（リンクなし / タップ不可）。
* `status_code === "delay"`: 橙〜赤色背景で `text` を表示し、`link_url` （または `has_detail`）が存在する場合のみタップで公式詳細ページへ別タブ遷移 (`target="_blank" rel="noopener"`).
* `status_code === "unknown"`: 灰色〜黄色背景で「公式運行情報を取得できませんでした（サイトをご確認ください）」と表示し、タップで真岡鐵道トップページへ遷移。


* **駅間走行位置**: 線形補完計算値 `progress`（`0.0` 〜 `1.0`）に基づき、駅間軸上の位置を推定描画する。
* **動的レーン割り当て**: 同一駅または同一駅間に存在する列車同士でグループ化し、`direction` ごとに動的に `laneIndex` を割り振って重なりを防止する。
* **上り（`direction: "up"`）**: `X = -1 * (32 + laneIndex * 28) px`
* **下り（`direction: "down"`）**: `X = +1 * (32 + laneIndex * 28) px`



### 7.2 ダイヤグラム（SVG）描画仕様

* **Y軸（距離軸）**: `stations.json` の `distance_km` に比例配置。
* **X軸（時間軸）**: `300` (05:00) 〜 `1740` (29:00) の1440分間（1分＝2px、横幅2880px）。当日の「最終列車到着時刻 + 30分」に動的フィットさせ、無駄な空白スクロールをカットする。
* **イベントデリゲーション**: SVGルート要素に `click` イベントを1つ設定し、`e.target.dataset.trainId` から対象列車を識別して詳細モーダルを呼び出す。

## 8. エラーハンドリング & 運用UI

### 8.1 バリデーション & 安全判定

* **データ構造チェック**: 受信した `today_status.json` のスキーマ検証を実施し、不正値が含まれる場合は警告を出力して対象データを破棄。
* **物理矛盾検出**: `can_exchange: false` の駅に上下列車が同時に `STOPPED` となる判定が出た場合、ブラウザコンソールに警告（`[Data Anomaly] Single track conflict detected`）を出力。

### 8.2 オフラインバナー仕様

GAS API通信失敗時、またはレスポンス破棄時は画面上部（ヘッダー直下）に **「オフライン運用モード（基本ダイヤのみ表示中）」** バナーを**常時固定表示**とし、リアルタイムデータ非反映であることを明確化する。
