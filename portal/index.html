鉄道ダイヤ・車両運用 統合システム

スジのドラッグ編集から時刻表、運用表、箱ダイヤ、車両基地在線バーまでを完全リアルタイム連動させた次世代の鉄道運行図表システム。従来の「スジを1分直したらすべてやり直し」から解放され、OuDia（.oud / .oud2）形式の読込や横長1枚出力・A4分割印刷にも対応。登録・インストール不要で、ブラウザからすぐにご利用いただけます。

01 / 直感的なスジ・時刻表編集

スジを掴んでドラッグ移動、秒ヒゲ・番線在線・セル右クリックからの当駅始発/直通化に対応。

02 / 全自動リアルタイム連動

ダイヤ修正が時刻表・運用表・箱ダイヤ・車両基地在線バーへ即座に反映されます。

03 / 既存資産活用 ＆ 印刷対応

既存の .oud / .oud2 読込対応。横長1枚出力からA4分割マルチページ印刷までプレビュー付きで完結。

真岡鐵道 公式運行情報・新着情報 自動通知サーバー（Discord）

自動監視・即時通知 参加無料

公式HP巡回監視 ＆ API 経由リアルタイム配信システム

真岡鐵道公式HPの運行情報および新着情報（公式発表）を常時巡回監視し、更新を検知した瞬間に API 経由で Discord へ自動配信する通知サーバーを運用しています。遅延・運休などの輸送障害や臨時列車・公式アナウンスをいち早く把握したい方に向けて公開しており、どなたでも無料でご参加いただけます。

01 / 運行情報の即時検知

列車の遅延・運休・運転見合わせなど、公式運行情報ページの更新を即座に通知します。

02 / 公式新着の自動配信

臨時運行やダイヤ改正・イベント案内など、公式HPの新着発表を見逃さずキャッチできます。

03 / 誰でも参加・通知調整可

Discord アカウントがあれば招待リンクからすぐ参加でき、スマホ通知の受け取りにも対応しています。
